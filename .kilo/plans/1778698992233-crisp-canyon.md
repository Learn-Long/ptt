# Plan: Fix scraper.py EOFError in Unattended Cronjob Mode

## Problem
When `scraper.py` runs as an unattended cronjob and PTT server times out, both `estimate_seven_day_index()` and `get_latest_index()` return `None`. The script falls back to `input()` which causes `EOFError` on empty stdin, crashing the entire pipeline.

## Root Cause
`get_start_index()` (line 96-118) unconditionally uses `input()` — there is no unattended/automatic mode.

## Current Workaround (Insufficient)
`auto_runner.py` (line 60-63) pipes `input="\n"` to `scraper.py` subprocess. This only works when `suggested` is not `None` (Enter accepts the suggested value). When `suggested` is `None`, pressing Enter just loops back to `input()` asking again, eventually failing.

## Fix Strategy
Modify `get_start_index()` to detect if stdin is a TTY (interactive terminal). If not (cronjob/pipe), use a **safe fallback default** instead of prompting.

### Fallback logic when stdin is not interactive:
1. If `suggested` is available → use it, and save to `last_index.txt` for future fallback.
2. If `suggested` is `None` → read the **last successfully estimated value** from `last_index.txt`. This is the previous day's estimate, which is a very close approximation (the board only advances ~30 pages/day, so yesterday's index is still valid for covering 7 days).
3. If `last_index.txt` also doesn't exist → retry `get_latest_index()` once with a short delay, then compute `latest - 200` as a last-resort fallback.
4. If everything fails → `sys.exit(1)` with a clear error message instead of hanging.

### Changes

| File | Change |
|------|--------|
| `scraper.py` | 1. Add `import sys` at top. 2. Rewrite `get_start_index()` to check `sys.stdin.isatty()`. 3. In non-interactive mode: if `suggested` is None, retry `get_latest_index()` once, then compute fallback `latest - 200`; if that also fails, read `last_index.txt`; if that also fails, `sys.exit(1)` with clear error. 4. After successfully determining start index, write it to `last_index.txt` for future fallback. |

### Detailed `get_start_index()` logic:
```
def get_start_index():
    suggested = estimate_seven_day_index()
    interactive = sys.stdin.isatty()

    if interactive:
        # existing input() loop — unchanged
        ...

    # Non-interactive (cronjob) mode
    if suggested is not None:
        print(f"自動採用建議值: {suggested}")
        save_last_index(suggested)
        return suggested

    # Use last successfully estimated value
    persisted = read_last_index()
    if persisted is not None:
        print(f"建議值不可用，使用上次記錄的索引: {persisted}")
        return persisted

    # Last resort: retry get_latest_index and compute fallback
    print("無歷史記錄，嘗試重新取得最新索引...")
    time.sleep(2)
    latest = get_latest_index()
    if latest is not None:
        fallback = max(1, latest - 200)
        print(f"使用回退值: {fallback} (最新索引 {latest} - 200)")
        save_last_index(fallback)
        return fallback

    print("錯誤：無法自動決定起始索引，且無歷史記錄可用。請手動執行。")
    sys.exit(1)
```

### Helper functions to add:
- `save_last_index(index)` — write index to `last_index.txt`
- `read_last_index()` — read index from `last_index.txt`, return int or None
